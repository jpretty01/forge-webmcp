# FORGE Judge Demo

## Core Story

FORGE makes WebMCP visible. Keep the laboratory, activity panel, approval queue, QA result, and registry in view as the story progresses.

## Reliable Sequence

1. Reset Ashen Reach.
2. Enter the lab and accept Garrick’s quest.
3. Run **Analyze dungeon**. Point out the three atomic inspection/simulation calls in Agent Activity.
4. Run **Propose +25% pressure**. Explain that no world state changed yet.
5. Open Approvals, inspect the structured parameters, and approve.
6. Run **BREAK MY GAME**. Open the critical progression deadlock.
7. Propose the narrow key relocation and approve it.
8. Retest. The deterministic regression should have zero progression failures.
9. Open Audit and roll back a checkpoint.
10. Open `/webmcp` and show tool schemas, read-only annotations, approval requirements, and reversibility.

## Recovery

Use **Reset demo world** at any time. The reset restores the key behind the locked sanctum door, initial player state, enemy behavior, quests, encounters, and QA baseline.
